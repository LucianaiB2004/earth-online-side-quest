# Demo 说明

《地球 Online 之人生支线》把生活里的几分钟变成像素冒险：AI 生成安全、低成本的小任务，完成后即时揭晓奖励；热点可转为世界事件和现实支线。无需登录、数据库或存档，刷新即清空。支持阿里云与 DeepSeek，演示内容明确标记。本次使用 Codex 开发，提供 Kiro 兼容的需求、设计和任务 Spec，未实际运行 Kiro。

## 演示顺序

1. 展示首页世界观与像素素材。
2. 打开 API 设置；隐藏密钥后再录屏，不录入或展示真实密钥。
3. 有可用凭证时测试连接、生成支线；没有时选择演示并说明标识。
4. 接受、完成支线，展示本次奖励；不将点击完成说成对现实行为的自动验证。
5. 打开 HUMAN SERVER，展示阿里云搜索结果及来源；未获真实搜索结果时使用演示事件并明确说明。
6. 选择合适的事件转化支线，说明新闻事实与游戏剧情的区别。
7. 刷新页面，展示状态清空；说明 GitHub Pages 静态架构。

真实 AI、联网搜索及线上部署只能在实际成功后展示为已验证；当前缺少真实凭证和远程部署结果时，不作相应成功宣称。
