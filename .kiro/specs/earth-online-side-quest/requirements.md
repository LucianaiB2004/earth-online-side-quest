# Requirements

本 Spec 根据根目录《项目开发提示词.md》《今日热点提示词.md》整理。本次由 Codex 实现，文件组织兼容 Kiro Spec，不代表执行过 Kiro。

## 产品边界

轻量、零账号、零数据库、零业务持久化的静态 Web 小游戏。没有真实多人服务器、累计属性、等级、历史记录、签到或排行榜。用户打开网页即可体验；主视觉始终是今日支线，设置为辅助入口。

## 验收需求

- R1：使用现有像素素材形成完整游戏界面，桌面、笔记本和手机可操作；弹窗、任务卡不得溢出。交互提供清晰焦点、加载和错误反馈，尊重减少动画偏好。
- R2：无密钥可生成标记为演示的安全任务。有密钥可通过统一 Provider 请求 AI，返回剧情、目标、步骤、类别、时长、难度、完成条件、奖励与可选替代方案。
- R3：任务状态为待接受、已接受、已完成或已跳过。只有接受后可完成；同一任务只能领奖一次；跳过与重新生成均有实际行为。
- R4：奖励仅完成后揭晓，只展示本次增量，不累计。九种属性为幸运、探索、勇气、善意、感知、羁绊、尊严、想象力、生命力。
- R5：设置支持阿里云与 DeepSeek、模型、Base URL、密钥显示/隐藏、连接测试、状态与清除。密钥只在页面内存，不写入 URL、日志或任何持久存储。
- R6：阿里云通过官方联网搜索获取热点并保留来源证据；本项目未接入 DeepSeek 联网搜索，不代表服务商自身没有搜索能力。允许用户提供新闻进行转换；不可用时提供独立标记的演示事件。
- R7：热点保留原始标题、摘要、来源链接与可确认时间，区分事实和 AI 游戏化叙事。无来源或未经核实的信息不标为真实今日新闻；不编造时间和在线统计；悲剧事件不强制转化任务。
- R8：任务生成与新闻转换独立；所有请求具备加载、防重入、超时、HTTP/网络/模型错误、结构校验与有限重试。失败不能伪装成功；任何演示降级必须显式标记。
- R9：任务安全、免费、低压力、可跳过，通常不超过 15 分钟；不要求危险、违法、侵犯隐私或强迫陌生人互动；社交任务提供非社交替代。
- R10：所有业务数据只保存在 React 状态或内存，刷新清空。没有 localStorage、sessionStorage、IndexedDB、Cookie 或后端数据保存。
- R11：生产构建为静态文件，项目子路径可用，提供 GitHub Pages 工作流、中文 README 和 200 字以内 Demo 说明。
- R12：实际运行、单元测试、浏览器交互和构建分别记录证据；真实 API 与部署在缺少凭证/远程环境时标为未验证。
