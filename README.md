# 地球 Online 之人生支线

主线由世界安排，支线由你触发。

[在线体验](https://lucianaib2004.github.io/earth-online-side-quest/) · [部署状态](https://github.com/LucianaiB2004/earth-online-side-quest/actions/workflows/deploy.yml)

像素风现实生活小游戏：生成一件几分钟能做的小事，接受、完成或跳过；完成后揭晓本次象征性属性奖励。没有登录、数据库、等级或累计属性。API Key、偏好、任务、奖励只在页面内存，刷新或关闭即清空。公开日报刷新后重新加载。

## 世界区域：直接读取 AIHOT 日报

来源为用户指定的 [AIHOT 日报 RSS](https://aihot.news/feed/daily.xml)，每天北京时间08:00发布，保留最近30期。标题、首段摘要、发布日期和链接直接来自 RSS，不经过模型改写。提供全部、今日、往期筛选、刷新及阅读入口。

该 RSS 未提供浏览器跨域读取许可，因此 GitHub Actions 每小时第17分钟及代码推送时，以 Python 标准库同步为站内 daily-news.json，随静态页面部署。页面每五分钟检查，也可手动刷新；不消耗模型额度，不引入代理服务或数据库。定时任务可能延迟，展示实际同步时间，超过两小时标记延迟。同步失败会让工作流失败，保留上一次已发布站点，不伪造最新数据。

更新频率为每日发布、每小时同步，不是逐秒新闻推送。内容由来源方提供，本站未独立核实所有事实。仅在用户点击关联支线时，将该期标题和摘要交给所选模型生成一个小任务。世界区域已移除模型搜索及新闻游戏化改写。严重伤亡等内容的关键词拦截仅为辅助，生成仍遵循安全提示。

保留 AIHOT 署名与阅读链接，内容归来源方及相应权利人所有。RSS 响应注明商业使用需书面授权，本项目不授予额外使用权。

## 使用

1. 无密钥可阅读日报；生成任务前需配置自己的 API Key。项目不再提供演示任务。
2. API 设置选择阿里云或 DeepSeek，点击官方获取密钥链接，回来填写自己的密钥。
3. 测试连接再生成任务，可随时修改兴趣与时长偏好。
4. 接受后可完成，奖励每条仅一次、不累计；也可跳过、换一个或取消请求。
5. 从日报触发关联支线，或点击生活探索、感知体验、创造一点意外，分别调用 AI 生成对应主题的新任务。

生成优先免费、室内或平地、1–3分钟的低压力行动，提供独处替代。玩家可拒绝任何不合适的任务。输出经过结构校验，一次重试包含具体错误原因；失败保留原任务并提示，不自动替换为演示任务。显示服务商、模型、等待耗时。

| 服务商 | 默认模型 | API Base URL |
| --- | --- | --- |
| 阿里云百炼 | qwen-plus | https://dashscope.aliyuncs.com/compatible-mode/v1 |
| DeepSeek | deepseek-flash | https://api.deepseek.com |

两家均只用于任务和连接测试，通过官方 chat/completions。高级设置可调整模型与地址。仅允许相应服务商的官方 HTTPS 域名，阿里支持白名单中的工作空间专属域名。按控制台地域配置；日报无需任何模型密钥。

密钥由浏览器直接发送至所选官方服务商，不经过本站服务器；开发者工具仍可查看请求。不使用 localStorage、sessionStorage、IndexedDB 或 Cookie 保存业务数据。不要把真实密钥放入代码、仓库、截图、URL 或部署配置。模型调用可能收费，以服务商实际计费为准。官方 CORS、网络和账号权限决定直连可用性，不关闭浏览器安全保护来绕过限制。

## 开发与部署

Node.js 22、Python 3.12（只同步公开 RSS，无额外 Python 依赖）。

```sh
npm ci
python scripts/sync-feed.py
npm run dev
npm test
npm run build
```

构建执行 TypeScript 检查并输出 dist。public/daily-news.json 是生成文件，不提交仓库，不包含用户数据。Vite 使用相对资源路径，支持 GitHub Pages 仓库子路径。

.github/workflows/deploy.yml 在 main 推送、手动触发及每小时定时触发时执行 RSS 同步、单元测试、构建和 Pages 部署。Pages 来源设为 GitHub Actions，不需要模型密钥。cron 为每小时第17分钟；GitHub 可能延迟或因长期无活动停用定时任务，界面同步时间会反映数据陈旧状态。

功能验收使用发布后的站点；构建成功不等于真实模型调用成功。首次体验报告保存在本地 docs/qa/2026-10-18-live-user-test/REPORT.md，针对更新前版本。旧 e2e 包含已移除的世界事件流程，仅为历史参考，不能作为当前日报版通过证据。

桌面采用导航、任务、日报三栏；长内容在面板内滚动，小屏自然纵向布局。世界时钟读取设备时间，按北京时间每秒更新，不是联网校时。HUMAN SERVER 为世界观设定。

素材来自用户提供的 UI素材包，归相应权利人所有。历史需求见 .kiro/specs/earth-online-side-quest/；实际实现工具为 Codex，不宣称运行 Kiro。
